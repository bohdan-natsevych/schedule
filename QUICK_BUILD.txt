================================
SCHEDULE MANAGER - QUICK BUILD
================================

PREREQUISITES:
✓ Python 3.8+ installed and in PATH
✓ Node.js 16+ installed and in PATH
✓ Inno Setup (optional, for installer)

SIMPLE BUILD:
1. Double-click: build.bat
2. Wait for completion
3. Find output in: dist\ScheduleManager\

OUTPUT FILES:
- dist\ScheduleManager\ScheduleManager.exe  → Standalone app
- Output\ScheduleManagerSetup.exe            → Installer (if Inno Setup installed)

DISTRIBUTE:
Option A: Zip the "dist\ScheduleManager" folder → Users extract and run
Option B: Share "ScheduleManagerSetup.exe" → Users install like any Windows app

TESTING BUILD:
1. Go to: dist\ScheduleManager\
2. Double-click: ScheduleManager.exe
3. Browser should open automatically
4. Test all features
5. Close console window to stop

COMMON ISSUES:

"Python not found"
→ Install Python from python.org
→ Check "Add Python to PATH" during install

"npm not found"
→ Install Node.js from nodejs.org
→ Restart command prompt after install

"Frontend build failed"
→ cd frontend\client
→ del package-lock.json
→ rmdir /s node_modules
→ npm install
→ npm run build

"PyInstaller failed"
→ pip install --upgrade pyinstaller
→ pip install --upgrade setuptools

"Inno Setup not found"
→ Install from: https://jrsoftware.org/isdl.php
→ Or ignore - standalone exe still works!

BUILD TIMES (approximate):
- Install dependencies: 2-5 minutes (first time only)
- Build frontend: 30-60 seconds
- Create executable: 1-2 minutes
- Create installer: 10-20 seconds
Total: ~5 minutes (first build), ~2 minutes (subsequent builds)

CLEAN BUILD:
To start fresh:
1. rmdir /s dist
2. rmdir /s build
3. rmdir /s frontend\client\dist
4. Run: build.bat

For more details, see BUILD.md
